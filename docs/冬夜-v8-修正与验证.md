# 冬季夜色显示修正 v8

日期：2026-11-14

## 修正

夜色原本随整个动景 SVG 一起受场景可见性控制。现在保留原画坐标中的静态夜色，流水、人物等动景仍按可见性暂停和隐藏。

- 冬景刚进入视窗、动景可见性通知尚未到达时，夜色层仍显示。
- 背景尚在加载时保留夜色墨罩，窗灯、星月和人物等内容等背景就绪后显示。
- 昼夜渐变是否推进改为依据整个画卷视窗是否可见，不再依赖刚切入的某幅画的动景可见性。
- 从天气面板切换昼夜时先刷新可见状态；暂停或画卷离屏时选择夜晚，直接保存完整夜色，避免“已选夜晚但渐变停在白天”。
- 离屏动景的交互内容继续隐藏，SVG 可访问性状态随可见性更新。
- 缓存版本更新到 v8。

## 验证

- 浏览器检查两幅冬景：冬日庭院、古渡雪岸的夜色墨罩透明度均为 0.760。
- 暂停后切白天、再切夜晚，夜色状态达到 1.000，暂停不再影响天黑。
- 开启冬雪后仍保持夜色，雨声为 0，提灯人物与窗灯保留。
- 20 项测试与 1776 项长卷导航断言通过，语法检查、git diff --check 通过，浏览器无 warning/error。
