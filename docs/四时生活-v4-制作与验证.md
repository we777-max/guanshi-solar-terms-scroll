# 四时生活 v4：屋舍装饰、炊烟与小动景

日期：2026-11-14

## 这次解决的问题

原先只在春卷第一景叠加了一小段低透明度烟，其他景上方的炊烟仍属于静态背景。现在八景均有可辨识的近处升腾炊烟，同时对原画远村烟的位置做局部、柔边扰动。新近烟从屋顶小烟道发出，逐渐上升、扩散、淡出，冬季烟略浓。没有给谷仓、亭子和桥梁添加烟。

房屋的主体、树木和地形保持原图静止，新增陈设不放在门洞、台阶、水渠或圭表入口上。

## 四季内容

| 季节 | 屋旁陈设 | 动景 |
|---|---|---|
| 春 | 花枝陶盆、柳编篮 | 蝴蝶、花瓣；保留原有麻雀、水鸭 |
| 夏 | 竹扇、竹席、水罐 | 蜻蜓、蝴蝶，荷塘第一景增加两只水鸭 |
| 秋 | 谷筐、簸箕、谷束 | 晒场边觅食麻雀、少量落叶 |
| 冬 | 柴薪、封口陶罐、草席 | 升腾炊烟、墙头/檐边麻雀、少量细雪、窗内暖光 |

全卷共新增 8 组陈设、13 处近烟和 8 处原画远烟动效。虫鸟分散在各自适合的场景，没有在冬季冰面上放游鸭或昆虫。雪花密度低，不是覆盖全画的暴雪效果。

这些是本幅四季画卷的生活意象，尚未根据地域、气温或真实物候记录驱动，也不是七十二候的逐条复原。没有新增被用户暂停的人物项目。

## 点击与暂停

- 点击陈设展开“檐下新绿 / 檐下纳凉 / 晒场收成 / 檐下冬藏”简短说明。关闭按钮或 Escape 收起，浏览画卷时自动收起。
- 蝴蝶、蜻蜓振翅回应，麻雀轻跳，水鸭点击泛起两圈涟漪。新增目标的按下、抬起不会传给画卷拖动。
- 八景沿用同一个播放开关；每景内烟、虫鸟、叶片、细雪、暖光均在该景 SVG 时间轴上暂停。
- 进入书房、离屏或页面进入后台时暂停；书房打开时自动收起陈设说明。
- 冰层仍是静止的，原有水流快慢与冰面点击判断保持。
