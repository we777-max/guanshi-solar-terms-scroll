# 春卷动景 v2 · 麻雀与水鸭

日期：2026-11-14。

## 效果与摆放

在第一景原有流水、炊烟和点击水面涟漪上增加三只小动物：

- 墙头一只麻雀，在原图坐标 (1690, 325) 一带短跳、偶尔展开翅膀，约 26 秒一个循环；点击或按 Enter/空格会轻跳回应。
- 院前一只水鸭，在 (1495, 650) 一带缓游；田边另一只较小的水鸭在 (540, 656) 一带活动。泳道横向约 85 像素，38 秒往返，转向时同步改变朝向。
- 水鸭有低透明度尾波和轻微点头，点击时当前位置产生两圈涟漪。泳道靠近岸边，避开右下角播放按钮。

沿用纸本淡彩、细墨线与低饱和褐色。鸟类是场景生活意象，并非各地节气物候的实时观测数据。树木、房屋与陆地继续使用原图，不做位移。

## 交互与暂停

所有新增动作均在同一个 SVG 时间轴上，继续由“动景已启 / 动景已停”控制。进入书房、第一景离屏、页面后台或用户暂停时统一冻结。系统减少动态效果设置继续默认暂停；该设置本次未修改做实机测试。

小鸟支持鼠标、触屏和键盘。鸟的按下/抬起事件由自身接收，避免触发长卷拖动；原来的拖动浏览、点水涟漪、二维圭表进入三维庭院和书房入口保持可用。

## 素材与实现

通过内置 image_gen 生成两张透明双帧 PNG，尺寸均为 1774 × 887，RGBA；以现有 `assets/scroll/spring.png` 为画风参考。原始输出直接复制到项目，保留透明度：

- `assets/motion/spring-sparrow-frames-v1.png`：收翅 / 展翅。
- `assets/motion/spring-duck-frames-v1.png`：抬头 / 低头。

`motion.js` 使用 SVG 裁切窗口切换帧，沿原图坐标叠放，新增同一 SVG 时间轴上的位移、朝向和一次性回应。没有新增动画库。基础长卷 PNG 未被改写。

## 验证

- 鼠标点击院前水鸭出现两个涟漪环，画卷横向位置保持 543 px。
- 点击麻雀和使用 Enter 均得到轻跳回应，画卷横向位置保持不变。
- 暂停时三只小动物均标记为不可互动。两次暂停画面对比，动景区域保持一致；像素差异仅在播放按钮悬停区域。
- 进入书房时动景状态为 `study`，退出后恢复；第一景离屏时为 `offscreen`，回到春卷后为 `playing`。
- 语法与空白检查通过；现有 9 项科学/行走测试及 1,776 条长卷导航断言通过。
- 实际截图：`春卷动景-v2-立春.jpg`、`春卷动景-v2-院前.jpg`。截图为静帧，动作请通过本地预览观看。
