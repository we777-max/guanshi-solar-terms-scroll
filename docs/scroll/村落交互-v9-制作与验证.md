# 水车停启与冬居年俗 v9

日期：2026-11-15。

## 启动与操作

在项目根目录运行 `python -m http.server 8771 --bind 127.0.0.1`，浏览器打开 <http://127.0.0.1:8771/index.html>，旧页面按 `Ctrl+F5` 更新。保持终端开着，`Ctrl+C` 停止。预览无需安装额外依赖。

- 全卷总览 → 溪桥水磨：水车默认开启。点木轮停止，再点恢复；Enter / 空格同样可操作。个人停启状态在本次页面内保留。
- 全局暂停、书房打开、切到后台、离屏时，水轮保持当前角度；恢复后继续，不会跳回起点。单独停轮不关闭溪流动景。
- 全卷总览 → 冬日庭院：点击右上角“冬居年俗”可选冬日平常、扫尘备年、除夕迎新、上元观灯。首入默认预览除夕。
- 点门旁春联换一副；备年阶段可点门旁贴上春联；点红灯笼可开关暖光，晚上更明显；上元会多挂两盏灯。
- 除夕点檐下爆竹，一串约 2.8 秒，响完后再次点击重新挂起，再点击可燃放。下雪或全局暂停时不点火。离屏、切时段、进入书房、静音和暂停会清理爆竹声音。

年俗使用农历阶段的小景预览，不是把立冬、小寒或大寒定义成春节。阶段切换仅控制年俗布置，画卷导航与天文观测日期仍按既有设置运行。本版交互位于冬日庭院，没有给整个冬卷统一贴上春联。

## 验证

- 单元测试覆盖水轮默认开启、角度保持、恢复，年俗阶段差别、爆竹雪天限制、暂停清理及重新挂起。
- WebAudio 检查共用声场、禁止重复叠响、暂停/静音清理。
- 浏览器检查：默认转动、鼠标停轮、键盘开启、全局暂停时角度保持；普通冬日无装饰；除夕门联、灯笼与爆竹分别响应；雪天点火被阻止；夜晚暖灯亮起。
- 浏览器音效状态确认：爆竹点响后声场为 running、爆竹声音处于播放状态；点全局暂停后声音关闭、爆竹交互完成清理。音效结束也会刷新状态，晴天无需天气渐变仍能正常同步。
- `npm test`：23 项测试、1776 项导航断言通过；音效完成通知变更后单独复测音效用例通过。素材索引、语法和空白检查通过，浏览器未记录 error/warn。
- 效果截图：`村落交互-v9-水车.jpg`、`村落交互-v9-冬居年俗.jpg`。
- 修正灯笼与人物透明热区重叠的问题；热区放在人群上层，可见装饰保留正常日夜着色。普通/隐藏阶段的按钮不会进入键盘焦点。
