# 二十四节气长卷：春卷样段制作方案

日期：2026-11-12

状态：用户已采纳“古画参考＋统一补绘＋程序动态”的方向，已完成第一张立春视觉概念图，等待画风与构图评审。图片位于 `素材/概念草稿/立春样卷-视觉概念-v1.png`，生成记录见 `docs/scroll/春卷样段-v1-生成记录.md`。尚未制作最终分层插画或开发网页。

## 1. 本轮交付

先完成一段能体现视觉风格与核心操作的春卷样段，再扩展全年。

本轮形成四项成果：

1. 一张横向完整场景概念图，用来确定构图、画风和细节密度。
2. 同一构图的冬末、早春两张环境状态图，用来验证环境变化。
3. 独立图层素材清单与可用性检查结果。
4. 一份交互分镜：浏览长卷、观察枝芽、操作圭表、返回画面。

先评审静态场景，再投入精细分层与动画制作。概念图用于表现效果，不能自动视为可直接制作动画的底图。

## 2. 暂定美术方向

- 场景：传统田园村落的艺术化再创作，以江南田园意象开展第一轮构图。
- 画面：暖米色纸底，细墨线，淡赭、灰绿、浅青；增强前后层次，保留阅读留白。
- 主参考：用户提供的《豳风图》局部，具体版本待核对。
- 动作与器具参考：《耕织图》；庭院生活与季节氛围参考《十二月月令图》。
- 建筑、地形、人物、器具统一视角和尺度后进入同一场景。
- 物候与农事按选定地域进一步核对；画面表达时令意象，不表示立春当天所有地点必然出现同样变化。
- 环境插画与现代天文计算分别记录依据。

## 3. 一屏构图

概念画面以约 3:1 横幅组织，最终制作尺寸在清晰度试验后确定。

从左到右：

田地与田埂 → 树木与村路 → 庭院书案 → 开阔测影场 → 河岸收尾

| 区域 | 主要内容 | 构图作用 | 可探索内容 |
|---|---|---|---|
| 左侧 | 少量田块、农人、农具 | 建立农耕主题，作为前后卷连接处 | 查看工具及准备农事的说明 |
| 中左 | 一棵可观察的树、村路 | 提供立春的主要自然观察点 | 枝芽局部对照 |
| 中部 | 低矮院墙、房屋、可见书案 | 容纳文献和生活细节 | 翻阅一则节气相关文献 |
| 中右 | 日照无遮挡的圭表与观察者 | 核心交互视觉中心 | 对比同地不同日期的正午影长 |
| 右侧 | 河岸、水面、少量植被 | 连续衔接后续画卷，平衡画面密度 | 轻量水纹反馈 |

远景山丘与天空保持简洁；可操作物件前方留出视觉空间。人物数量先以 4—6 人评估，优先建立动作与场景的关系。

## 4. 两种环境状态

两种状态共享建筑、道路、树干位置与镜头，便于比较。

| 元素 | 冬末状态 | 早春状态 | 制作要求 |
|---|---|---|---|
| 树木 | 疏枝、灰褐为主 | 部分枝梢增加细小芽点 | 树干固定，芽点独立 |
| 地表 | 枯草、裸土 | 零星新绿 | 变化限定于局部区域 |
| 人物 | 冬日生活活动 | 增加整理农具、院中活动 | 厚衣保留，动作另做 |
| 庭院 | 门窗相对闭合 | 部分门窗开启 | 开闭部件分别制作 |
| 光色 | 稍冷、低饱和 | 略暖，增加浅绿 | 与枝芽、人物状态共同变化 |
| 声音 | 轻风为主 | 少量鸟鸣与活动声 | 默认由用户开启 |

本轮的时间移动表达一段冬末至早春的过程，节气节点作为导航标记。画面不在跨过立春标记的一瞬间整体变绿。

## 5. 交互分镜

### A. 浏览与发现

用户横向拖动或操作节气导航进入样段。时间标记与环境状态保持对应。首次出现简短操作提示，提供直接定位方式。

### B. 枝芽观察

用户点选树枝 → 出现局部放大 → 拖动对照签查看冬末与早春的枝梢 → 收起后返回原画位置。

枝芽用于物候观察，说明中注明地域背景。第一版不需要复杂生长动画。

### C. 圭表测影

用户点选圭表 → 显示地点、日期及观测条件 → 拖动日期，对照同一地点不同日期的正午影长 → 查看简短原理 → 返回原画。

全年日期与日内时刻是两个概念。本轮先固定当地太阳正午比较日期，影子方位与长度由模型确定，避免混用一天内和一年内的变化。采用简化模型时注明演示假设；具体数值后续核验。

### D. 文献阅读

用户点选书案 → 展开经核对的一则原文、释义与出处 → 可关联对应观察点 → 收起返回。

古籍文字使用单独排版层；插画中的书页预留文字位置。

## 7. 执行顺序与评审点

1. 选材：核对《豳风图》版本，筛选可用场景、农人、器具参考，填写素材清单。
2. 构图：制作一张春卷概念图；评审连续性、细节密度、画风、重点是否突出。
3. 环境：基于同一构图制作冬末与早春状态，检查建筑与树干对齐、季节变化是否自然。
4. 分层：整理无人背景、人物、植物、圭表、遮挡层与文字层；检查透明边缘及移除物件后的背景。
5. 交互：制作枝芽、测影、书页三段分镜，再进行可操作样段开发。
6. 扩展：样段成立后，建立全年24节气的场景表与复用素材规则。

## 8. 样段通过标准

- 一眼能读出田园生活与早春意象，人物和器物融入同一画风。
- 横幅具备连续向两侧扩展的空间。
- 环境状态变化不引起建筑、树干、道路错位。
- 用户能发现观察点，完成操作后回到原位置。
- 圭表显示明确的日期、地点及观测条件，解释与演示一致。
- 文献有可核对的版本与出处，图像有来源记录。
- 全屏与预定放大倍率下清晰度足够；无法满足时回到素材阶段处理。
