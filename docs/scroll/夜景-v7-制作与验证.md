# 夜景遮挡、场景固定与提灯 v7

日期：2026-11-14

## 修正内容

- 窗灯、月亮、星星、彩虹、檐口滴水和水面雨圈移入各幅画卷自有 SVG；用原画 2172 × 724 坐标定位，不再等屏幕天气 canvas 根据滚动位置补画。
- 夜色墨罩和窗灯也在原画坐标中，平移、缩放和全屏布局时与背景同步。屏幕 canvas 仅保留自由下落的雨雪、云色和闪电。
- 星月和彩虹共用山体天际线及前景树冠遮挡蒙版。星点只生成在开放天空，蒙版还为树枝边缘留出保守余量。彩虹低处被山体、树冠遮住。
- 同一视窗只显示一颗月亮。当前月亮随所属画卷离开视窗后才交接到下一场景，不在相邻画卷接缝重复显示。
- 彩虹记录雨停时所属的场景。浏览同一夏季的另一景时不会把彩虹搬到新视窗中央；离开夏季或再次降雨时按原天气规则收起。
- 夜间田间歇作、店铺收摊，保留提灯归家的路人。晴夜手提纸灯笼；雨夜一手撑油纸伞、一手提灯；冬夜左臂保留柴薪，右手提灯。灯笼暖光与脚边小范围光晕共用人物的行走、转身和双帧动作。
- 夜行人物的标题、按钮提示和点击说明也随昼夜切换。

## 月亮模型与日期

月相和视大小使用已在项目内固定版本的 Astronomy Engine 计算，而非按四季任意指定大小：

- GeoMoon 的地心距离换算为千米，图中半径按 384400 / 距离进行相对缩放。
- 月球实体半径按 1737.4 km，视直径为 2 × asin(实体半径 / 月地距离)。
- MoonPhase 决定盈亏及明暗分界，Illumination 提供亮面比例。朔附近亮面太小时不绘制月亮。
- 默认随当前节气的日期，采用东八区当日 20:00 计算；「天候 → 观月日期」可选择日期作对比，也可点击「随节气」恢复自动。
- 日期对比实测：2026-12-11 的月地距离约 406388.3 km，图中半径 24.593；2026-12-24 的距离约 356662.1 km，半径 28.022，相对大小差约 13.9%。
- 夜景月亮的天空位置仍是画卷构图示意，不声称按地点计算了真实方位、月出月落或当时地平高度。星点是氛围星空，不是精确星图。遮挡采用保守的矢量轮廓，不是逐片树叶的像素级抠图。

科学依据：

- NASA 2026 Moon Phase and Libration：https://svs.gsfc.nasa.gov/5587/
- 美国海军天文台月相与视大小说明：https://aa.usno.navy.mil/faq/moon_phases
