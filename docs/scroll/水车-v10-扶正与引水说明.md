# 水车扶正与引水 v10

日期：2026-11-15。

## 启动与操作

在项目根目录运行 `python -m http.server 8771 --bind 127.0.0.1`，打开 <http://127.0.0.1:8771/index.html>。旧页面按 `Ctrl+F5` 刷新，在“全卷总览”选择“溪桥水磨”。保持终端开着，`Ctrl+C` 停止服务。

水车默认开闸进水、转动。点击轮子关闸，进轮水流停止；再次点击提闸恢复。旁侧原有跌水和溪流继续流动。全局暂停时，水轮和新加的进轮水流一起停在当前状态；恢复时继续。

## 修正

- 上一版轮面的投影含有横、纵斜切。本版去除斜切，前后轮面竖直，轴心等高，轮轴与原画固定石座对齐。只用横向压缩表达侧视透视。
- 将轮面与连接板的投影统一为 `src/village-model.js` 的 `MILL_WHEEL` / `projectWheelPoint`，避免部件分别使用不同角度。
- 在原有水槽旁增加分水槽及小闸板，水流从槽口抵达右侧轮缘，再沿轮缘下落并汇入水磨前的溪潭。
- 增加轮缘滴水和入溪水花；流纹、滴水、水花与水轮共享动画时钟，最高约 30 fps。关闸时新加的进轮水流消失，旁侧跌水不受单独开关影响。
- 新增水槽和水流使用 SVG 图层，不覆盖或改写原始绘画、木轮 PNG。图层继续使用现有夜色覆盖与场景暂停规则。

## 验证

24 项单元测试和 1776 项长卷导航断言通过。新增检查覆盖轮面上、下端同一竖线，左、右端等高，前后轮面对应点等高。

浏览器验证：默认 `vertical / flowing`；关闸后 `closed`、进轮水流透明度为 0，原场景仍为 playing；停轮角度连续两次检查均为 9.48°；键盘重新开启后可恢复，整体暂停状态为 `paused`、水流保持静止，恢复后为 `flowing`。浏览器无 error/warn。
