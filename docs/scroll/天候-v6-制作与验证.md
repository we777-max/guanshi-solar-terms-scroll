# 昼夜、雨雪与声场 v6

日期：2026-11-14

## 操作

通过 http://127.0.0.1:8771/index.html 打开长卷，旧页面 Ctrl+F5 刷新。工具栏的「天候」打开设置。

- 白天 / 夜晚：约四秒过渡。夜间星月淡现、窗内暖灯亮起，田间歇作，街市收摊、往来人物减少。
- 下春雨 / 下夏雷雨 / 下秋雨 / 下冬雪：随视窗所在季节切换。同一个降水选择在冬景变为雪，不叠加雨。
- 雨雪约十秒渐起；「晴 / 渐停」约九秒渐歇。中途反向切换接着当前雨势变化，不先跳回零。
- 春雨细缓，夏雨密急，有间隔较长的单次柔和闪电与延迟雷声，秋雨居中；冬雪缓落，冰面保持静止。
- 夏季白天持续降雨、雨势完整渐停后，彩虹淡入，约三十八秒内淡去。夜雨、冬雪、很快取消的小雨、换季、再次降雨均不误触发。闪电可独立关闭。
- 环境声可独立开关、调音量。第一次点击天气选项后，由用户手势解锁浏览器声音。音色使用本地 Web Audio 程序合成，不请求外部音频服务。

## 场景联动

- 农人在雨起时换成斗笠版本；挑担人加短蓑衣；赶集行人与提篮顾客换成完整撑油纸伞的双帧人物。
- 夏季雨势变大后田间人物停止劳作、淡出，檐下出现避雨村民；秋雨中收割与筛簸停止，冬雪中露天劈柴暂停。夜晚同样歇作。
- 麻雀、蝴蝶、蜻蜓在降水时隐去；雨停一小段时间后回来。水鸭在夜晚和夏季暴雨时避入隐蔽处。
- 屋檐落水点按原画檐口坐标配置。水面雨圈只出现在既有可流动水域，冬季冰面不生成雨圈。
- 雨势增强时水平水纹更密、雨圈变大，水流动画加速；跌水原本就比平面水流急。只改变水流的动画时长，不加速人物。
- 雨雪中近景动态炊烟由不受 SMIL 透明度控制的父层渐隐。原画远处固定白烟使用 AI 无烟背景的局部羽化蒙版盖住，不替换整幅原画。梯田原画无需远景去烟覆盖。
- 按下总动景暂停，天气保持当前画面；进入书房、页面隐藏或画卷离屏，声场静音、停止天气推进。雨雪设置仍可保留，返回后继续。

## 声音与性能

只有一个 AudioContext、一个雨声循环和一个流水声循环。雷声是短暂声源，结束即释放。

流水声按当前可见画面中的水源距离选择、左右定位和衰减：水磨跌水强，普通平缓河面轻，冬季活水弱。滑出视窗时渐弱并交接到新水源，不为八幅画各自播放一条循环。雨声按雨势渐强渐弱；冬雪不播放雨声。切晴、暂停、静音、进入书房或离开页面会取消尚未播放的雷声。

天气粒子绘制在一个透明 canvas 上，以约 30 fps 绘制可见区域；静态晴景停止 requestAnimationFrame。原画坐标只在滚动、尺寸和可见性改变时集中测量。昼夜采用透明墨色遮罩，不逐帧滤镜处理全部大图。人物继续共用原有场景 SVG 时钟。

## 科普表达边界与依据

雨势、昼夜与活动是本项目可自由切换的四季叙事，不是实际天气预报，不表示全国同一节气有同样天气。星月用于夜景氛围，未绘制实时天文星图。彩虹的「夏季白天雨后」是本项目演示规则，现实中其他季节也可能见虹。

彩虹演示参考中国天气网关于雨后残留水滴、阳光及观察方向的说明：https://sh.weather.com.cn/tqxs/05/1871677.shtml 。本版绘制一条淡彩虹作为光学现象提示，未计算观察者和太阳的三维几何。
