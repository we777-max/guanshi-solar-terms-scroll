# 圭表测影 v1

制作日期：2026-11-13。

## 模型与体验

长卷保留二维国画，通过工具栏和春卷庭院入口进入独立三维观象台，再返回长卷入口。三维模型包含石质台面、南北向圭面、青铜竖表、刻度、米制数字与方位标识。模型为科普示意，不对应某件实物的精确复原。

- 表顶中心高于圭面 2.00 米；圭面长 6.00 米，每 0.1 米一刻度。
- Blender 建模坐标：X 东、Y 北、Z 上。glTF 导出后：X 东、Y 上、Z 南，北方为负 Z。
- 圭面基准高度 0.30 米。最高表顶为 2.30 米。
- 160 个网格、32664 个三角形；GLB 约 2.2 MB，没有运行时外部贴图。
- 网页支持24节气、三个观测地点、2024—2030节气循环、斜看、俯看、复位、旋转缩放、冬夏虚线对照、巡览四时。
- 进入页面默认不自动播放。系统减少动态效果时取消镜头缓动；离开标签页会停止自动巡览。
- 三维加载失败时显示已渲染的模型静帧，明确标注；数值仍可选择，不将静帧当作实时阴影。

## 科学约定

1. 用 Astronomy Engine 2.1.19 搜索太阳视黄经到达目标值的时刻。立春从315°开始，每气增加15°。
2. “2026立春—次年大寒”为一轮，包含2026年立春至2027年大寒。最后小寒、大寒的真实日期位于次年。
3. 日期按北京时间确定。对交节所在日，分别求该观测地点的太阳上中天、日出、日落；交节时刻与测影时刻分别显示。
4. 使用当日当地太阳上中天时的太阳中心几何高度计算影长，不计大气折射。正午并不等于北京时间12:00。
5. 影长 L = H / tan(h)。太阳单位方向为 d，表顶到基准水平面的投影为 x=-H·dx/dy，z=-H·dz/dy。太阳灯光、实体阴影、影端标记与数字使用同一结果。
6. 日出、日落采用引擎的标准折射模型；显示的是两者时间差。它与几何中心过地平线的理论昼长略有不同。
7. 地点采用近似城市坐标：洛阳34.6°N/112.5°E，北京39.9°N/116.4°E，杭州30.3°N/120.2°E；均以海拔0米计算，不计地形遮挡。
8. 时间显示四舍五入到分钟，内部计算保留完整时间。米制刻度用于教学，不把古籍中的尺换算为固定现代长度。

## 文件与生成方式

- `scripts/build_gnomon.py`：可审查的原生 Blender Python 建模脚本。
- `assets/gnomon/gnomon-v1.blend`：Blender 5.3.0 源场景，包括相机和参考光照。
- `assets/gnomon/gnomon-v1.glb`：只导出模型，网页另行设置实时太阳光照。
- `assets/gnomon/gnomon-preview.png`：Blender Cycles 渲染的静帧，不是截图或生成式图片。
- `assets/gnomon/model-info.json`：表高、基准、轴向及几何数量。
- `vendor/`：固定 Three.js 0.180.0、Astronomy Engine 2.1.19 的浏览器资源和许可证；可从锁文件重建。

本次使用独立后台 Blender 脚本实际生成和导出模型。会话后半段已出现 Blender MCP 工具，但状态、场景查询均返回未连接 Blender，故没有把本次制作声称为经 MCP 完成，也未修改用户正在编辑的场景。

## 校验与参考

- 科学计算测试覆盖24节点的时间顺序与黄经、跨年、日影方向、影长比例、夏冬顺序、纬度效应、异常输入。
- 2026年春分与夏至同香港天文台公布时刻作两分钟容差核对。
- 浏览器已验证实际 GLB 加载、夏至短影和冬至长影、地点与年份切换、俯视和对照；手机宽度375 CSS像素无横向溢出。
- 洛阳2026年：夏至正午太阳高度约78.84°、影长0.39米；冬至约31.96°、影长3.21米。数值对应此示意模型与近似坐标。
- 圆盘与原有长卷导航仍通过原先1776项事件及几何模拟断言；该模拟不替代实际浏览器渲染。
