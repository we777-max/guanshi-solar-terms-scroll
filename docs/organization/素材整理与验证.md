# 素材目录整理与验证

日期：2026-11-15。

## 启动说明

只看素材：双击根目录 `素材总览.html`，默认展示书房，支持按模块筛选、搜索、打开原图和展开效果截图。

体验项目：在根目录运行 `python -m http.server 8771 --bind 127.0.0.1`，浏览器打开 <http://127.0.0.1:8771/index.html>。书房入口在春季第一景；三维庭院为 <http://127.0.0.1:8771/courtyard.html>；试摆页为 <http://127.0.0.1:8771/placement.html>。终端保持开着，`Ctrl+C` 停止，更新后按 `Ctrl+F5` 刷新。完整步骤及命令/端口问题见根目录 `README.md`。
