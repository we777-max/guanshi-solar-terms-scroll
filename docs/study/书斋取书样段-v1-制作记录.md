# 节气书斋 · 取书样段 v1

日期：2026-11-12

## 体验流程

春卷第一景的书房标记“入室阅书” → 进入独立室内 → 从木书架选择一册书 → 书移动至案上 → 翻开此书 → 阅读与翻页 → 合上书 → 放回原位 → 返回长卷。

保留进入前的长卷位置；进入书房时收起节气圆盘、目录并停止拖动。一次取阅一册，移动过程中暂停其他取书操作。Escape 先合书，再归位，最后退出书房。室内使用原生 dialog 保持键盘焦点范围，关闭后焦点回到入口。窄屏可横向查看室内；书页改为上下排列。图片延迟到进入室内时载入，失败可重新展开，关闭后迟到的加载回调不会重新打开书房。

## 本版书目与内容

每册均为 2 页原典摘读，附自主编写的简明解读与观察提示，提供原典链接；不是整本古籍扫描阅读器。

- 《月令七十二候集解》：立春、春分。https://zh.wikisource.org/zh-hans/月令七十二候集解
- 《淮南子·天文训》：二十四时、日夜。https://www.shidianguji.com/book/SBCK089/chapter/1j713d3s4tatv_7
- 《周髀算经》：立表测影、注文。https://zh.wikisource.org/zh-hans/周髀算經_(四庫全書本)/全覽
- 《齐民要术》卷一：农事与天时、因地为时。https://zh.wikisource.org/zh-hans/齊民要術_(四庫全書本)/卷01

古文采用公版原典节录，简繁与标点统一整理。书房、装帧、书名题签为交互设计示意，不是文物影像或历史场景复原。天文计算尚未接入。
