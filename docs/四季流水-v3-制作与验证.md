# 四季流水与冬季覆冰 v3

日期：2026-11-14

## 本次场景效果

- 溪桥水磨：补上上游、桥下汇流、水磨出水潭、三级跌水、桥下石坎和溪口水纹。水流沿原画水道向前景汇聚，建筑、水轮与岸石保持静止。
- 秋收晒场：补上田间窄渠和石桥下的溪水。
- 山麓梯田：补上弯曲灌溉渠、桥下汇流和浅坎水纹。
- 夏季两景：前景平缓河面也接入统一动景，荷塘桥下补上水流；荷叶与亭桥保持静止。
- 冬日庭院：缓水覆冰，溪口留窄小的活水带。
- 古渡雪岸：岸边覆冰，桥洞到前景保留水道。冰面使用同画风的霜纹、冰裂和冰下倒影。
- 原春卷第一景的流水、炊烟、1 只麻雀与 2 只水鸭保留。

这里的结冰范围是本幅雪景的美术表达，没有按地区、气温、水深推算封冻日期，也不表示所有地方整个冬季都会结冰。

## 交互和动画边界

全卷共用右下角动景开关。离开视窗的场景、进入书斋、切到后台时暂停 SVG 时间轴；系统偏好减少动态时默认暂停。冬季冰层始终静止，不随水流变形。

未结冰水面支持点击泛起涟漪，冰面不触发水波。按下后拖动画卷不生成涟漪。小鸟交互及进入书房保留。

平河面的线条漂移约 5 原画像素/秒，窄渠约 18，跌水约 52。它们用于表现视觉上的缓、急关系，**不是水力计算结果**。SVG 原画坐标为 2172 × 724，实际屏幕速度随画卷缩放。

每个水域均有独立遮罩，原始背景图片不修改。冬季冰层还与真实岸线取交集，并扣除活水带，避免覆盖桥墩和码头。冬景新增的位图仅在冰面遮罩内显示。

- `motion.css`：水流、水花与冰缘样式。

## 冰面素材来源与完整提示词

使用内置 image_gen 工具，编辑模式；分别以 `assets/scroll/winter.png` 和 `assets/scroll/winter-ferry.png` 为编辑目标，非透明输出。两幅分别调用，提示词相同。生成后复制到上述项目路径，原始背景与生成源文件均保留。项目展示只取两幅新图的水面部分，其他部分仍使用原图。

```text
Use case: lighting-weather.
Asset type: frozen-river layer for an existing Chinese antique interactive handscroll.
Edit target: the supplied complete wide painting. Preserve EXACT composition, camera projection, crop, buildings, bridge, dock, shoreline, trees, mountains, snow and aged paper color. No new objects, people, text or borders.
Change ONLY the visible water: render the river as naturally frozen, translucent muted grey-olive ice, warm ivory frost, a few irregular delicate angular branching cracks, cloudy trapped-bubble patches and low snow dust along the banks, with faint softly obscured reflections beneath the ice. Match the original very fine ink outlines, mineral washes and mottled old silk-paper grain. The ice must look painted into this same old Chinese landscape, rich and subtle, not a smooth solid vector shape, not bright blue or photorealistic. Freeze all visible foreground water, even the center; the application will reveal an original moving-water channel with a mask later. Keep every land object and its silhouette in precisely the same location. Return the complete 3:1 painting at high resolution.
```

## 验证记录

- `node --check motion.js` 与 `node --check water-motion.js` 通过。
- 原有 `npm test`：9 项天文/庭院测试和 1776 项长卷导航断言通过。
- 浏览器实测：三处溪流均有连续帧差异；水磨跌水、溪道与前景河面的像素随时间变化，房屋及田地取样区域不变。
- 水磨暂停前后两张截图完全一致（逐像素比较），验证暂停同时停止跌水、水面与水花。
- 冬季点击冰面，涟漪数量为 0；点击活水，产生 2 圈涟漪。
- 春卷点击水鸭仍产生 2 圈涟漪。进入书斋后，八景时间轴均为 study 暂停态。
- 窗口内只有相邻可见场景处于播放态，其他场景为 offscreen。
- 浏览器控制台未见 warning/error。
