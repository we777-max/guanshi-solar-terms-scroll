# 画中圭表 v1

日期：2026-11-13。

将春卷庭院中的文字入口替换为可点击的二维圭表。器物独立于背景，采用透明 PNG，随同画卷缩放、移动；原背景没有重绘。圭表放在右侧铺砖庭院，尺面落在地面范围内。平时无边框，鼠标靠近或键盘聚焦时显示“走近观影”；触屏保留小提示。工具栏的“寻圭表”先定位画中器物，点击器物再进入现有测影页面。

资源：`assets/guibiao/scroll/gnomon-scroll-v1.png`，1536 × 1024，RGBA。使用内置 imagegen，以 `assets/scroll/backgrounds/spring.png` 作为画风和透视参考生成。此为教学插画，不是出土文物照片；画中静态日影用于表现器物，数值模拟在测影页面中进行。

画中位置以春卷原图为基准：左69%、顶53%、宽16%，以较浅的地面透视显示，保证表脚与尺端均落在院内砖地范围。原图2172 × 724，器物不占用新的界面高度。

验证：桌面与375 CSS像素窄屏下器物正常加载；窄屏“寻圭表”可完整定位器物，页面无横向溢出；点击器物进入测影页面，返回后回到长卷；浏览器控制台无警告或错误。原有科学计算和导航检查通过。页面截图保存在 `docs/guibiao/画中圭表-v1.jpg`。
