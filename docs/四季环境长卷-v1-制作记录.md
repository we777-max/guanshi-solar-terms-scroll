# 四季环境长卷 v1：生成与使用记录

日期：2026-11-12

用户要求：先完成长卷环境，人物、文物和书籍以后再加入。

本轮通过内置 imagegen 生成四段纯环境背景。春段基于用户已认可的概念图移除人物、动物、便携物件及圭表；其余三段以已有场景作画风和相邻布局参考。每段保留田地、村路、庭院、河岸等固定环境，为后续分层内容预留空间。

输出：`assets/scroll/spring.png`、`summer.png`、`autumn.png`、`winter.png`。

本轮环境为四季艺术化意象。24个节气节点在预览中用于导航，尚未建立各节气的独立物候状态或接入天文数据。相邻画面在网页中以有限区域渐变叠合，未达到逐像素无缝；以后可在接缝定稿时继续局部修绘。当前无人物、文物、书籍交互。
