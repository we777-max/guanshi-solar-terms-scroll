# 悬浮节气圆盘

日期：2026-11-12

圆盘位于画卷右上角，与现有八景导航共用当前节气状态。默认收成64像素小圆盘，手机端56像素；点击后浮层展开完整圆盘。页头恢复紧凑高度，展开不会改变画卷尺寸。采用原生 SVG 绘制，无额外依赖和图片资源。

## 交互

- 立春位于正上方，二十四节气顺时针排列；春、夏、秋、冬各占一段。
- 朱砂色指针随当前节气转动，中心显示节气与“春生、夏长、秋收、冬藏”对应文字。
- 点击圆盘节气，复用长卷定位；拖动、滚轮、四季按钮、进度条、节气目录及总览均同步到圆盘。
- 当前节气和季节分别高亮。圆盘表达场景浏览进度，尚未接入实时天文计算。
- 收起状态保留小指针与当前节气；选定节气后自动收起。收起按钮、Escape或点击圆盘外部也能关闭，键盘关闭后焦点返回入口。
- 圆盘与节气目录互斥展开，减少画面遮挡。
- Tab 可进入各节气；方向键移动圆盘内焦点，Home/End 移至首末标签，Enter/空格定位。
- 遵循减少动态效果设置。手机端仍悬浮在画卷角落，展开面板限制宽高并允许内部滚动。
- 进入全屏后切换为沉浸布局，画卷使用100dvh，标题、底部进度与总览收起，保留圆盘入口、画面左右浏览按钮与退出全屏按钮。退出后恢复原布局。
