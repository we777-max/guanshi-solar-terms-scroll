# 农事与街市 v5 制作与验证

日期：2026-11-14

## 本次内容

在原有八景长卷上叠加独立的透明二维人物，原背景文件未改动。

| 画中区域 | 活动 |
| --- | --- |
| 春日田地、溪桥田畦 | 牛拉木犁，农人扶犁；木柄锄整理田土 |
| 夏日水田 | 两位农人弯腰分秧插植，村路行人往来 |
| 夏日水乡长街 | 米铺、布铺、茶摊；三位店家、三位提篮顾客、三位行人和一位挑担人 |
| 秋日田园、山麓梯田 | 四位农人持短镰割稻；禾场筛簸；挑担运粮 |
| 冬日庭院、古渡岸路 | 劈柴备薪，厚衣村人束薪归家 |

全卷新增 29 位普通村民和 1 头耕牛，分散在八景中，店家计入 29 人。人物为通用村民，不是此前暂停的郭守敬人物项目。

## 历史参考与表达范围

- 农事工序参考故宫《胤禛耕织图册·收刈页》的耕织图工序说明：https://www.dpm.org.cn/collection/paint/231818.html
- 该馆藏单页画的是麦田；本次依照用户的稻作叙事绘制弯垂稻穗，仅取其农事工序作为参考，未将该单页当作稻作图或宋代服饰复原依据。
- 街市参考故宫《清明上河图》所呈现的店铺、摊点与往来人群：https://minghuaji.dpm.org.cn/paint/detail?id=592d80e225aac624977fee2e19452c1f&topicType=12
- 图中采用朴素布衣、头巾、木柄农具、竹筐、扁担、短柄镰刀，避免现代机械。属于古代田园科普插画，不声称精确复原某一朝代。
- 春耕、夏种、秋收、冬藏是画卷叙事概括。插秧说明明确标注各地稻作时序不同，不把某节气当作全国统一农时。

## 交互与实现

- 人物使用双帧透明 PNG，在原图坐标中确定脚点和尺度，田间脚部使用局部原画遮挡。
- 店家位于原有柜台后，米粮、布匹与茶具放在柜面；店招轻摆。
- 农具、肢体作小幅双帧循环，挑担人和村民沿人工设置的岸上道路短距离往返。
- 点击人物或商铺打开活动说明；Enter、Space 可打开，Escape 关闭并回到原目标。科普卡带馆藏参考链接。
- 与水流、炊烟、小动物共用场景 SVG 时钟；暂停、离屏、进入书房、页面隐藏均沿用既有控制。
- 这是可交互的动态插画，尚未实现持续收割导致田地清空、作物生长模拟或真实交易库存。

入口：index.html。建议通过项目 HTTP 服务打开 http://127.0.0.1:8771/index.html ，刷新旧页面可按 Ctrl+F5。

## 验证

- 三份改动 JavaScript 通过 node --check。
- npm test：9 项天文与庭院测试通过；1776 项长卷导航断言通过。
- 原生浏览器逐景检查人物脚点、田地遮挡、店家/顾客朝向与岸上路线。
- 实测米铺在暂停时仍可打开说明；农事说明支持 Enter、Space、Escape。
- 进入书房时农事说明收起，八个场景全部切到 study 暂停状态，返回可继续浏览。
- 同位置两帧真实截图比较：播放时 13075 个像素的通道差超过 12；暂停截图逐像素完全相同。
- 控制台无新增 warning/error；git diff --check 通过。
- 截图：农事街市-v5-春耕.jpg、农事街市-v5-夏种.jpg、农事街市-v5-秋收.jpg、农事街市-v5-冬藏.jpg、农事街市-v5-街市.jpg。
