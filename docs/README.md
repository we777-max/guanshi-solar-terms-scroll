# 制作记录与效果截图

## 启动说明

在项目根目录打开终端（不要在 `docs` 文件夹里启动），运行：

```powershell
python -m http.server 8771 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8771/index.html>。书房在春季第一景点击“入室阅书”；三维圭表庭院可直接打开 <http://127.0.0.1:8771/courtyard.html>；道具试摆为 <http://127.0.0.1:8771/placement.html>。

只看素材可直接双击根目录 `素材总览.html`，也可打开 <http://127.0.0.1:8771/素材总览.html>。终端需保持运行，`Ctrl+C` 停止；更新后 `Ctrl+F5` 刷新。也可用 `npm run preview` 启动，无需先安装 npm 依赖。命令或端口问题见根目录 `README.md`。

## 归档目录

| 模块 | 目录 | 主要内容 |
| --- | --- | --- |
| 书房 | `study/` | 书斋取书流程、四册古籍来源、背景/书册提示词、书架/取书/翻阅/窄屏截图 |
| 长卷 | `scroll/` | 四季背景、节气圆盘、流水、四季生活、农事街市、天气、夜景与验证截图 |
| 圭表 | `guibiao/` | 二维入口、三维庭院、测影实现、阴影调整、三视图参考与截图 |
| 道具试摆 | `placement/` | 文房用具、农具、秋收器具的提示词、书房与晒场试摆截图 |
| 本次素材整理 | `organization/` | 归档说明、启动步骤、检查结果和素材总览截图 |

`素材归档映射.json` 记录本次归档前后的文件路径及 SHA256；图片、遮罩和模型内容保持不变。历史制作记录中的运行素材路径已同步为新路径；生成器原文件路径保留用于溯源。

根目录 `素材总览.html` 提供模块筛选、原图预览和截图展开。完整文件索引位于 `assets/catalog.json` / `assets/素材索引.csv`。
