# 春卷水烟动景 v1

本版按最终要求只让河水和炊烟动。全部树木、房屋、地面保持原图静止，不再保留任何树木或柳枝动画。

## 效果与交互

- 春卷第一景：河面有轻微水纹和缓慢移动的水光，厨房屋顶处叠加三缕错开循环的淡灰炊烟。
- 点击水面产生两圈椭圆涟漪。长卷拖动继续用于浏览，拖动不触发涟漪。
- 右下角“动景已启 / 动景已停”控制播放、暂停。暂停保留当前画面，烟囱等静态图形不会随开关消失。
- 离开第一景、进入书房或页面切到后台时暂停；返回时依据播放开关恢复。
- 系统设置“减少动态效果”时默认暂停，用户可主动点击播放。动态全部使用同一 SVG 时间轴，暂停也会停止水纹、水光和炊烟。

## 实现范围

`motion.js` 在第一景叠加 SVG。复用 `assets/scroll/spring.png`，没有改写背景 PNG。

动态重绘的背景图使用河岸轮廓裁切，并限制滤镜范围为原图 y=560～724；树木与建筑始终使用原来的静态图像。`assets/motion/spring-water-mask.svg` 提供靠岸逐渐减弱的水域遮罩，水纹采用小幅位移，水光采用低透明度线条平移。烟囱及炊烟为独立 SVG 图形，炊烟缓慢上移、扩散并淡出。

只在春卷第一景做示范，其余七景保留原有浏览和书房功能。圆盘仍表示场景导航，当前动态不由天文模型计算驱动。

## 验证

- 实际浏览器验证播放 / 暂停，暂停时保留当前图层。
- 实际点击河面生成 2 个涟漪环；拖动画卷后涟漪环为 0。
- 切到夏景后状态为 offscreen，动景按钮收起；返回春景状态恢复 playing。
- 进入书房后状态为 study，关闭书房后恢复播放。
- 动态图层不包含 wind-field；过滤图像明确受河道裁切，滤镜上界为 y=560。
- 检查过程中浏览器控制台无 JavaScript 错误。
- JavaScript 语法检查与原有圆盘 / 长卷导航模拟检查通过。系统减少动态效果的分支由代码实现，本次未修改系统设置做实机测试。
