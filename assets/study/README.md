# 书房模块素材

## 启动与入口

在项目根目录（不是当前素材文件夹）运行 `python -m http.server 8771 --bind 127.0.0.1`，浏览器打开 <http://127.0.0.1:8771/index.html>，点击春季第一景的“入室阅书”。点击书架书册 → 放到案上 → 翻开 → 翻页 → 合书 → 放回书架。书房嵌在主页面中，没有独立的 `study.html`。

只看本模块图片和截图，双击根目录 `素材总览.html` 即可；默认打开书房分类。服务需保持终端开着，`Ctrl+C` 停止，修改后按 `Ctrl+F5` 刷新。首次预览无需安装依赖。

## 文件说明

| 文件 | 用途 | 当前接入情况 |
| --- | --- | --- |
| `interior-v1.png` | 1659 × 948 书房室内背景，空书架、空书案 | 已用于进入书房后的背景，也被试摆页复用 |
| `books-v1.png` | 1536 × 1024 透明四列书籍图集，每列 384 × 1024 | 已用于取书、翻阅和归位；题签文字由网页叠加 |
| `stationery-v1.png` | 毛笔、笔架、砚台、墨锭、砚滴等文房用具 | 目前仅在 `placement.html` 的书房视图试摆 |
| `books-content.json` | 四册古籍的题名、来源、摘读、解读及书架裁切位置 | 从 `study.js` 自动生成，便于查阅；页面仍以 `study.js` 为准 |

四册书为《月令七十二候集解》《淮南子》《周髀算经》《齐民要术》，每册两页摘读。书房图像是项目生成的设计素材，非古画或文物扫描。原典来源链接与完整提示词保留在 `docs/study/书斋取书样段-v1-制作记录.md`；文房用具提示词在 `docs/placement/道具试摆-v1-制作记录.md`。

界面位于根目录 `index.html` 的 `#studyRoom`，逻辑在 `study.js`，样式在 `study.css`。入口是春季第一景的“入室阅书”。书房动效由 CSS 与 JavaScript 完成，没有单独的视频文件。

书架、取书、翻阅、窄屏效果截图都在 `docs/study/`。根目录的素材总览默认展示本模块，展开“制作记录与效果截图”即可查看。
