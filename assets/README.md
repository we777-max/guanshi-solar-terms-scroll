# 项目素材目录

## 启动与查看

只看素材：双击项目根目录的 `素材总览.html`，默认展示书房素材，不需要启动服务。

体验交互：在项目根目录打开终端，运行 `python -m http.server 8771 --bind 127.0.0.1`，保持终端开着，再用浏览器打开：

- 素材总览：<http://127.0.0.1:8771/素材总览.html>。
- 长卷与书房：<http://127.0.0.1:8771/index.html>，书房入口是春季第一景的“入室阅书”。
- 三维圭表庭院：<http://127.0.0.1:8771/courtyard.html>。
- 道具试摆：<http://127.0.0.1:8771/placement.html>。

按 `Ctrl+C` 停止服务。可用 `npm run preview` 代替上述 Python 命令，不必同时运行；预览不需要安装 npm 依赖。遇到旧图或旧路径按 `Ctrl+F5` 刷新；Python 命令和端口问题见根目录 `README.md`。

## 模块目录

直接打开项目根目录的 `素材总览.html`，可按中文模块查看缩略图、文件路径、用途、制作记录和效果截图。页面可双击打开，无需联网。素材按模块存放，程序引用各自目录里的原文件。

| 模块 | 文件夹 | 内容 |
| --- | --- | --- |
| 书房 | `study/` | 室内背景、四册书图集、文房用具、古籍摘读内容 |
| 长卷 | `scroll/` | 八景背景、动景、四季居民、天气覆盖图与试摆农具 |
| 圭表测影 | `guibiao/` | 二维入口、三维庭院、早期模型、建模参考 |
| 道具试摆 | `placement/` | 试摆布局配置；图片复用其他模块 |
| 人物样稿 | `characters/` | 现有郭守敬造型草稿，尚未接入主卷，本轮未并入正式素材索引 |

`catalog.json` 是完整素材索引，`catalog.js` 供离线总览页面读取，`素材索引.csv` 可用 Excel 打开。清单区分当前使用、试摆和参考；图像尺寸、透明通道、原文件大小、引用脚本和 SHA256 均记录在索引中。

添加或替换素材后，在根目录执行 `npm run assets:index` 更新索引；`npm run assets:check` 检查文件和引用是否有效。索引脚本不改动图片内容。

没有单独图片文件的内容：长卷炊烟、部分流水与涟漪、雨雪、闪电、星月、窗灯、彩虹和实时日影由代码绘制；雨声、雷声和河流声由 WebAudio 生成。对应脚本见 `scroll/README.md`。

制作记录已按模块归档到 `docs/`；用户提供的参考图与早期概念稿在根目录的 `素材/`。
